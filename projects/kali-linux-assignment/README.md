# Kali Linux Command-Line Fundamentals

## Project Overview

This hands-on cybersecurity lab used Kali Linux in Oracle VirtualBox to practice essential Linux command-line skills and collect clear technical evidence from the terminal.

## Purpose

The purpose of the project was to build practical familiarity with Linux system navigation, system identification, hardware information, and basic network-connectivity testing while documenting the results in a structured report.

## Tools Used

- Kali Linux
- Oracle VirtualBox
- Linux terminal / command line

## Practical Work Completed

- Verified the current working directory with `pwd`
- Reviewed system and kernel information with `uname`
- Reviewed processor and CPU information with `lscpu`
- Tested network connectivity with `ping -c 2 8.8.8.8`
- Identified the active Linux user, host, and operating environment
- Captured terminal screenshots as evidence and compiled the work into a final project report

## Skills Demonstrated

- Linux command-line navigation
- Basic system administration awareness
- Network-connectivity testing
- Technical evidence collection
- Cybersecurity documentation
- Troubleshooting and command validation

## GRC Relevance

Linux command-line literacy supports GRC and audit work because security professionals often need to understand system evidence, review technical outputs, validate configurations, and communicate clearly with technical teams. The project also reinforced the importance of accurate, traceable evidence for audit readiness and control verification.

## Evidence

Project evidence includes terminal screenshots showing the commands used and their outputs, together with the completed assignment report.
